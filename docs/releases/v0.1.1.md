# claude-usage v0.1.1

默认端口改为 **127.0.0.1:43190**，首次访问 Dashboard 与未指定语言的命令行现在默认使用**中文**。

- URL 的 `?lang=`、浏览器中手动保存的语言、CLI 的 `--lang` 和 `CLAUDE_USAGE_LANG` 继续生效。
- 中英文 README 新增实速功能演示 GIF、高清 MP4、六平台下载表、安装说明与界面截图。
- 演示覆盖分钟查询、小时/月历下钻、项目、任务树、搜索、Fast 与模型组合筛选、CSV 导出、Windows/WSL 来源、缓存价格和显示设置。
- 录制包含平滑光标、逐字输入与阅读停顿，不加速播放，全部使用合成数据；可运行 `npm run capture:media` 重现。

已有 `config.json` 中保存的端口不会被覆盖。如需将已有安装从 43191 改到 43190，先停止已有服务，再修改状态目录 `config.json` 的 `port` 并重新启动。本次升级不修改计量数据、Claude 配置或数据库 schema。

The default address is now **127.0.0.1:43190**, and new dashboard visits and CLI sessions default to **Chinese**. Explicit language preferences remain effective.

Both READMEs now include real-time synthetic GIF walkthroughs, full-resolution videos, a six-platform download table and clearer onboarding. Existing configured ports are preserved; stop an existing service before changing `port` and restarting. No accounting data, Claude configuration or database schema changes are required.
