# claude-usage v0.1.0

首个独立版本：本地 Claude Token 统计、Windows/WSL 自动来源发现、全局请求去重、压缩与 Advisor 迭代计量、缓存期限计价，以及暖色中英双语 Dashboard。

- 概览、每日月历、小时下钻、分钟范围、任务树、搜索、组合筛选与 JSON/CSV 导出。
- 独立状态目录与端口 `127.0.0.1:43191`，不修改 Claude 配置。
- 来源失败或日志删除保留已收集历史；改写/截断需要明确同意重建。
- 当前公开 API 单价的 Token 等价估算，**不代表订阅扣额或真实账单**。
- 用户级安装、自启、诊断和卸载；更新采用 SHA-256 校验、备份及失败恢复。

下载对应系统/架构，校验 `SHA256SUMS`，使用 `serve` 前台运行。需要开机启动时再主动运行 `install`。macOS 安装包为未签名命令行程序，系统是否允许执行取决于本机安全设置。

First independent release: local Claude token accounting, Windows/WSL discovery, global request deduplication, compaction/Advisor iterations, cache-lifetime pricing, and a warm bilingual dashboard. Cost is a token-equivalent estimate at current public API prices, not a subscription charge or actual bill.

Six standalone binaries cover Windows, Linux and macOS, each for amd64 and arm64. Verify `SHA256SUMS`; use `serve` without installing a service, or explicitly run `install` for user startup. macOS binaries are unsigned command-line programs.

See [README](https://github.com/zJay26/claude-usage/blob/main/README.md), [English documentation](https://github.com/zJay26/claude-usage/blob/main/README.en.md) and [validation scope](https://github.com/zJay26/claude-usage/blob/main/docs/validation.md).
